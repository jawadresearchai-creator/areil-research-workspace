# Hostile Peer Review
Prompt: find what is wrong, not confirm quality. Attack novelty, controls, confounding, estimand, stats, overclaiming, selective citation, unsupported mechanism, missing negative results, figure/table inconsistencies and journal fit. Every finding needs location, failure mode, severity and repair test.
