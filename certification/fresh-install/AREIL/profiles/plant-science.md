# PLANT SCIENCE PROFILE

Use crop/species/cultivar and developmental stage explicitly. Distinguish greenhouse/pot/hydroponic/field context. Track substrate/soil, environment, treatment dose/duration, replication unit and batch/block structure. Search agronomy/plant physiology plus molecular routes when relevant.

Gene-expression routes (qPCR, RT-qPCR, RNA-seq, transcriptomics, differential expression) are **permitted when genuinely feasible or when authentic public data are reanalyzed**. Never write a wet-lab qPCR experiment as performed if it was not performed. Public omics reanalysis must name accession, sample mapping, preprocessing and limitations.
