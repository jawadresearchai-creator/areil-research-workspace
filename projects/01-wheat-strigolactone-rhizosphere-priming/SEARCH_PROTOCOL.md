# SCHOLARLY SEARCH & RETRIEVAL PROTOCOL

**Date Started:** 2026-09-05  
**Version:** 1.0  
**Databases / Scholarly Endpoints:**
- Crossref REST API (`https://api.crossref.org/works`)
- PubMed / NCBI E-utilities
- Europe PMC REST API

## Inclusion Criteria
1. Primary research articles and authoritative reviews published in peer-reviewed scholarly journals.
2. Direct investigation of strigolactone biosynthesis, transport, or perception in Poaceae (wheat, rice, maize) or model angiosperms.
3. Arbuscular mycorrhizal symbiosis signaling, hyphal branching, and host colonization kinetics.
4. Functional characterization of mycorrhiza-specific phosphate transporters (*TaPT4*, *OsPT11*, *StPT3*).
5. Interplant chemical signaling or common mycorrhizal network (CMN) transport mechanisms.
6. 100% active, verifiable DOI registered on Crossref with exact bibliographic metadata match.

## Exclusion Criteria
1. Predatory journal publications, unrefereed preprints lacking empirical verification, or non-peer-reviewed blog posts.
2. Incomplete DOIs returning HTTP 404 on Crossref.
3. Studies lacking empirical data or peer-reviewed experimental assays.
