# AREIL RESEARCH PROJECT

This directory is canonical for the project's research state. Chat history is not canonical.

- `raw/` immutable source/user data and source documents where permitted.
- `derived/` scripted transformations.
- `analysis/` code, logs, result objects.
- `manuscript/` source and rendered manuscript artifacts.
- `ledgers/` structured source/evidence/claim/contradiction/novelty/review records.
- `audits/` citation, reproducibility and consistency audits.
- `system/` preflight, telemetry and task records.
